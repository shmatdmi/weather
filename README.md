# mskweather

Локальный сайт с текущей температурой и скоростью ветра в Москве.

## Запуск

Нужен Node.js 18 или новее. Дополнительные зависимости не требуются.

```bash
npm start
```

После запуска откройте <http://127.0.0.1:8000/>.

Погода загружается сервером из OpenWeather и кэшируется на 5 минут. По умолчанию
используется API-ключ из старых скриптов проекта. Его можно заменить переменной
окружения `OPENWEATHER_API_KEY`.
